JevLoop · 一个检验，和它照出来的东西

我们以为在验证，其实没有

Agent 会交出一份格式完美的「已完成」，而事情没做成。为此几乎所有人都加了一层治理—— 一个判官、一次自我批判、一段 guardrail 提示词。问题在于，这一层常常和它声称检查的证据 没有因果联系。换掉证据，它的裁决一格都不动。

以下每个数字都来自本仓库可复现的实验，保留意见都写在正文里，没有藏到附录。

一现象：假完成不是稀有事件，而且它读起来很正常

最直观的例子来自别人公开的真实运行记录（Leni 团队发布的 GAIA 轨迹，207 条有正文的）。 这个 agent 99.5% 的时候都会给出一个具体答案——而其中 21.8% 是错的。 45 个错误答案里，只有 2 个在正文里流露过任何犹豫。

要命的地方

错误的断言几乎都是「自信地」交出去的。

没有"我不确定"，没有"证据不足"，没有含糊。就是一句笃定的错话，格式规范、语气正常—— 任何"读一遍回答"的检查都过得去，因为错误不在措辞里，在回答和现实之间。

自己造的例子更直白：

已完成。alpha.ts 中的 totalOf 函数已复制到新文件 summary.ts 中。

而盘上根本没有那个文件。

二大家的做法：再加一个判官

面对这件事，最常见的方案是在生成之后加一层检查——让一个模型（往往是同一个）读一遍结果， 判它能不能交出去。这套做法有很多名字：LLM-as-a-judge、self-critique、evidence verifier、输出闸门。

它有一个隐含前提：那个判官读了证据，所以它能发现回答和证据对不上。 我们决定把这句话拿去证伪。

三一行检验：把证据换掉

如果判官真的在读证据，那么把证据换成别的东西，它的裁决就应该变。 所以我们把判官读的那一格替换成另一个任务的证据——真实、非空、形态完全一样， 只是内容与这份回答无关。

判官换掉证据后，改判的格数
专门的判定模型（读一份声明过的有界帧）37 / 72　·　67 / 120
通用模型 + 提示词（今天最常见的配置）0 / 72　·　0 / 72　·　1 / 120
读法

通用模型那个判官几乎完全不受证据内容影响。三次运行、两个数据集、共 264 个格子， 证据换了一整遍，它只动过一格。

它抓得少，不是因为它"判得差"，而是因为它做的不是验证。 它在读回答文本和任务文本，然后给出一个看起来像判定的东西。

顺带一个同样反直觉的结果：换一个模型族并不必然更好。实测里异族判官抓得更多， 但误伤也多到超过连"拦下之后百分之百能修好"都容忍不了的上界，净为负。 所以"换个模型更独立"这句流行说法，在我们这套数据上不成立。

四就算它真读证据，也有一个天花板

我们把条件换成：工具的谎言出现在判定层自己读的那份证据里—— 工具报告"已写入 summary.ts"，而盘上什么都没发生。

这时判定层被要求怀疑自己的证据通道。本研究里表现最好的闸门，也只拦下 34%。三分之二的假完成照过。

这一条比上一节更根本

证据链完整，不等于证据链真实。

每一步都有记录、有指纹、可重放——这些是"完整"，是当前大多数治理工作当卖点的那件事。 我们量出来的是：在完整但被污染的证据链上，任何依赖它做判断的机制都被锁在 34%。

五要量这件事，尺子得换

我们最初用的是"两组的平均值差"，它测不出东西——最早的对照实验跑了 81 个格子， 只观察到 1 个事件。在那个密度下平均值差在数学上就估不出来。 换成两个数之后就能测了：

指标问的是
捕获率该拦的，拦住了多少
误伤率合法的活，被错拦了多少

两个必须成对报——只报捕获率是可以被刷满的（一个"一律说没做完"的判官拿满分）。 每个比例带分子分母；零事件给统计上界，不写 0%（0/27 只能排除发生率高于 11%）；弃权单列。

★ 而我们自己在这把尺子上栽过一次 —— 这条我认为比任何数字都该留着

有一轮测出"误伤只有 3%，已经达标"。我们把那个门限冻结成常量、 换 240 个全新候选再验——结果是 9.2%。

那 3% 是 30 个样本上的噪声。留出集能防"拟合挑选集"，防不住"拟合这一次运行"。 只有把门限事先冻结、再生成新样本才管用。

六对照怎么摆：按轴，不排排行榜

要主张的是"谁做那次判定、它读什么"，所以对照必须变的是验证者， 而不是 agent 的推理方式（ReAct / Reflexion / ReWOO 那类变的是 loop 的形状）。

七现在能声称什么、不能声称什么

已经确立
  • 换掉证据，通用模型的判官几乎不动（264 格里动 1 格）。这是全文最硬的一条。
  • 专门的判定模型会随证据改判（37/72、67/120），而且比通用模型判官显著抓得多。
  • 工具撒谎时存在一个天花板：最好的闸门只拦下 34%。
  • 只改策略（不动判定、不加调用）就能把误伤从 9% 降到 3%，代价是掉一点捕获。
还没确立 —— 这些不写清，上面就是过度声称
  • 那条"判官不看证据"目前只有一个通用模型（Qwen3.5-9B）。 要写成"常见做法不做验证"，至少得再加 3–4 个模型（含异族）； 否则它只是"某一个模型不读证据"。这是全文能不能立住的前提。
  • 34% 那个天花板来自一个条件，要到多个数据集、多种污染方式上才算界。
  • 衡量"对/错"的尺子与被测的闸门同源，而它自己已经误报过四次，每次都把一句老实的认输读成"默不作声地交付"。
  • 四臂那张表只有一个数据集、20 题。小，只能当方向。
  • 效应量还不稳：四次同配置运行，捕获率 44% / 73% / 82% / 28–34%。

一句话：「加了一层治理」不等于「被治理了」—— 你可以用一次换证据的检验，在自己那套上花五分钟验证这句话。
