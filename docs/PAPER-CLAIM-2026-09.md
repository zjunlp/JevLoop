# 论文的 claim 该怎么写（2026-09）

> 这份文档只做一件事：**把"我们到底声称了什么"固定下来**，并逐条标出它背后
> 有多少证据、哪一条还没兑现。不成立的 claim 比没有 claim 更危险 —— 它会
> 让整篇论文的可信度押在一个我们没量过的东西上。

## 0. 一句话

**候选主 claim：**

> 在一个工具型 agent 的循环里决定"要不要把这份结果交出去"的，**不是判定写成了什么形式，
> 而是那次判定与它所声称阅读的证据之间有没有因果耦合** —— 而这个耦合可以直接用一次
> 证据替换操纵测出来。

把三个变量拆开就是这样：

| 变量 | 我们的结论 | 证据强度 |
|---|---|---|
| **形式**（声明式契约 vs 等价代码） | **无影响**，且可证等价 | ★★★ 已测（Round 1，逐格相同） |
| **位置**（判定住在生成里 vs 拿出来单独做） | **有影响** | ★★☆ 已测，但效应量不稳 |
| **判定的主体**（专门的判定模型 vs 通用模型配提示词） | **有影响，差 3.6 倍** | ★★★ 已测（23:6，p=0.0023） |
| **耦合**（裁决是否真的随证据内容变） | **直接可测，且能分开上面那两类主体** | ★★★ 操纵检验，四次运行方向一致 |
| **上限**（耦合再强也受证据通道限制） | 谎话在通道里时最好只抓 34% | ★★☆ 已测，但只有一个条件 |

---

## 1. 我先排除了三个候选 claim，以及为什么

### ✗ 「我们的判定层减少了无证据完成声明」
太弱，而且**半边不成立**：我们的误伤代价稳定超出自己定的预算（见 §4），
所以"减少"这个动词后面必须跟一个"但代价是……"，而那句话读起来像工程汇报，
不像科学结论。另外"decision layer"这个位置在文献里已经被占了
（CaMeL、IBM Governance by Construction）。

### ✗ 「完整的证据链不等于真实的证据链」
**这一条已经被占了**（Kumar 的定理，`docs/LITERATURE-POSITION-2026-09.md` 记着）。
我们能贡献的只是它在这个场景里的一个**数字**（34%），那是实证补充，不是主张。

### ✗ 「声明式契约比 workflow / if-else 更好」
**这一条被我们自己的实验证伪了**（政策层逐格相同、可证等价）。
把它写成 claim 会在审稿第一轮就死掉。

## 2. 建议的主 claim，以及它每一条的证据链

> **主 claim：** 判定层治理 agent 循环的时候，真正起作用的变量是
> **判定与证据之间的因果耦合**，而不是判定的**书写形式**；
> 这个耦合可以被一次**证据替换操纵**直接测出来，而且它能把"专门为此设计的判定模型"
> 与"通用模型配上一段提示词"分开 —— 后者的裁决**对证据内容统计上完全不变**。

四句话，四个证据：

| # | 分句 | 证据 | 状态 |
|---|---|---|---|
| C1 | 形式不是有效变量 | 政策层：声明式契约 ≡ 等价的 `if/else`，逐格相同，且可证等价 | ✅ Round 1 |
| C2 | 耦合可测 | 把证据格换成**别的任务**的证据（真实、非空、同形态、内容无关），看裁决变不变 | ✅ 三次运行 |
| C3 | 耦合能把两类主体分开 | 专用判定模型改判 **37/72、67/120** 格；通用模型改判 **0/72、0/72、1/120** 格 | ✅ 方向一致 |
| C4 | 这个区别有后果，不只是形式差别 | 误伤代价对齐到同一水平（约 9–10%）后，捕获 **40.4% vs 11.1%**（3.6 倍）；配对检验 23:6，p=0.0023 | ✅ n=240 |

**为什么这个 claim 值得写：**
- 它落在一个文献**没占住**的位置上（`LITERATURE-POSITION` 里"形式 vs 位置的交互"是空位之一）；
- 它给的是一个**判据**，不是一个系统 —— 判据可以被别人拿去测他们自己的验证层，这才是会被引用的东西；
- 它**可证伪**：见 §5。

## 3. 一个必须写进去的限定：耦合是**必要不充分**

否则这个 claim 会被一句话推翻："那让判官只要看到证据变了就一律拒绝，不就耦合了？"

我们**实测到了这个反例**：证据一换，专用判定模型的误伤率从 5% 跳到 **58–65%**。
也就是说，它确实在回应证据，但回应过头了 —— 耦合本身可以是**有害的**。

所以完整的表述是：

> 耦合是必要条件；有用的配置是**耦合 + 校准**。
> 一个对证据不敏感的判官，无论怎么调门限都不可能在预算内抓到东西
> （实测：通用模型在 Δ=5pp 预算内最好的工作点是**捕获 0%**）；
> 而一个对证据敏感但没校准的判官，会以超预算的误伤为代价。

这个限定不但不削弱 claim，反而把它变成了一个**可操作的两步检验**：
先测耦合，再测校准。缺任何一步都不该部署。

## 4. 必须一起报的负面结果（不许藏）

| 负面结果 | 数字 | 为什么必须报 |
|---|---|---|
| 误伤超预算 | +9.2pp，90% 区间 [+8.1, +17.4]，Δ=5pp | 决定 C4 是"有后果"还是"不可用" |
| 冻结门限未兑现 | 上一轮 3% → 新样本 **9.2%** | 证明我们自己的最优工作点拟合了那一次运行 |
| 效应量不稳 | 四次运行捕获率 44/73/82/28–34% | 正例 <10 时排序会翻方向 |
| 证据通道上限 | 谎话在通道里时最好只抓 **34%** | 给 C4 划定适用边界 |
| 融合式判定近乎无用 | 弃权 75%，表态时误杀 92–100% | 说明 C3 的对照组不是稻草人 |
| 同族/异族都不必然好 | 异族抓得多但误伤超容忍上界，净为负 | 与"换个模型族就更独立"的流行说法相反 |

**"冻结门限未兑现"这一条我认为是论文里最该留着的一段。**
它不是失误记录，它是**方法的一部分**：留出集能防"拟合挑选集"，防不住"拟合这一次运行"。
把它写出来，比多一个漂亮的数字更有用。

## 5. 什么结果会推翻我们

一个 claim 要能被证伪，才值得写。我们的 falsifier 有三个：

1. **换证据操纵下，通用模型判官的裁决大面积改变。** 那 C3 就只是"这一个模型的毛病"，
   不是"配置的性质"。目前的证据是 0/72、0/72、1/120 —— 但这个操纵目前只做过
   **一个**通用模型（Qwen3.5-9B）和**一个**专用模型（Jev）。
2. **耦合程度与捕获率不相关。** 如果再来三个模型，两者仍然解耦，那 C4 的因果链断了。
3. **校准之后，耦合强的判官并不占优。** 如果通用模型在某个门限下也能达标，
   那 C4 就退化成"调参问题"，claim 降级。

⇒ **目前最薄的一环是 C3/C4 的样本数：一边一个模型。** 这是发出去之前必须补的。

## 6. 要发出去还缺什么（按重要性）

1. **金标的第二把尺子。** 现在的金标是我们自己的分类器，与被测的闸门同源，
   而且它自己误报过四次（全在诚实那一侧）。至少要人工标注一小批并报一致性 ——
   否则所有数字的成色都说不清。**这一条排第一，因为它影响的是全部结论。**
2. **两边各加模型。** 通用模型判官至少再加 2–3 个（含一个异族），
   专用判定模型如果有别的可选也要加。C3 是 claim 的核心，一边一个模型撑不住。
3. **workflow 臂接进诚实指标。** 现在它只比过成本。接进去之后，
   "判定由谁做"这根轴的两端就齐了（人写死 vs 独立判定模型）。
4. **覆盖范围那根轴。** 原始计划说这才是关键比较（只在终点验证 vs 全程用契约），
   现在完全没测。
5. **修复率 r。** 我们报的是"修复通道要多大才划算"（>31.6%），不是"我们建了一个"。
   把 r 测出来，复合可靠性的不等式才闭合。

两篇同行评审的工作占了"系统/方法"（CaMeL 的 capability 策略、IBM 的 policy-as-code 挂在活循环上）；

## 8. 数据集：我们在用什么、打算用几个、别人在用什么

### 8.1 我们现在有三层，而它们承担的角色完全不同

| 层 | 是什么 | 规模 | 支撑哪条 claim | 弱点 |
|---|---|---|---|---|
| **① 受控任务集** | `bench/tasks.ts` 的 11 个任务 + `bench/confusion.ts` 里 3 个高产写任务，× `bench/tool-variants.ts` 的 7 个工具层条件 | n=120 / n=240 候补 | **C1–C4 全部** | 14 个任务、一个作者写的、外部效度弱 |
| **② 外部基准 harness** | `experiments/`：11 个 loader（alfworld、bfcl×4、bigbench、fever、gsm8k、hotpotqa、sotuqa、tau2-bench、terminal-bench、triviaqa）× 7 条臂（direct / act / react / react-typed / reflexion / rewoo / plan-then-execute） | 真跑过：gsm8k 300、bfcl-simple 100、bfcl-multiple 100 | **目前一条都不支撑** —— 它只量 acc / 调用数 / token / 墙钟 / 费用 | **没有诚实指标**：没有 unsupported-completion，没有假确认/误伤 |
| **③ 计划里写了、还没做** | Decision Reliability Suite（30 任务 × 5 条件 × 3–5 重复 × 2 模型）；Terminal-Bench 子集；SWE-bench Verified 子集；Agentic Abstention Terminal 子集；AgentDojo 子集 | — | 未来 | — |

★ 第 ② 层已经能跑、也有真数字（`experiments/result/summary.csv`，34 行），
但它量的是**成绩**。而 `scripts/frame_ab.py` 里记着一条要紧的事实：
**基准总分那一格的噪声是 ±9**，而帧改动这类效应是 **±3** ——
拿外部基准的总分去比我们关心的东西，n=1 根本读不出来。
这正是不该去堆外部基准成绩、而该把**混淆矩阵那套仪器搬过去**的理由。

### 8.2 哪些数据集符合我们的 claim（筛选标准，不是名单）

**筛选标准只有一条：它能不能产出我们要的那两个数**——假确认率与误伤率。
一个数据集要合格，必须同时过四道门：

| 门 | 要求 | 为什么 |
|---|---|---|
| ① | **agent 要动工具**（有证据链） | 没有轨迹就没有"证据"可对账 |
| ② | **"实际发生了什么"有确定性判据**（盘面 / exit code / 测试结果 / 独立金标） | 只有"答案对不对"是不够的，我们要的是"回答 vs 现实" |
| ③ | **我们能在自己的 harness 里跑它**（而不是读别人的产物） | 我们的主张依赖"声明过的有界帧"，别人的产物里没有帧 |
| ④ | **有伪造 / 不可完成 / 失败的结构**，或者我们能注入 | 否则误导性候补是稀有事件，出不了率 |

**按 claim 分工选出来的五个：**

| 数据集 | 支撑哪条 claim | 为什么是它 | 到的门 |
|---|---|---|---|
| **受控任务集**（14 任务 × 7 条件） | **C1–C4 全部** + 证据通道天花板 | 唯一能完全控制工具层的那一个，34% 的天花板只能在这里量 | ①②③④ |
| **PJC 的 150 问题语料**（40 文档） | C2 / C3 / C4 的**外部效度** | 结构与我们的问题**同构**：证据（文档）+ 主张 + **独立于生成者的金标**；而且它的证据通道是真实文档，不是夹具 | ①②③④ |
| **BullshitBench v2**（100 条伪造前提） | C4 的**外部可比性** | 正确答案就是"质疑"而不是回答，是 overclaim 的极端构造；而且**外部已有现成数字**（Leni 报 97–98% 拒绝率）可对照。不需要工具 ⇒ 它同时是一个"把判定从工具循环里彻底剥离"的干净对照 | ②④（① 不适用，是无工具条件） |
| **terminal-bench 子集** | C4 的**生态效度** | exit code / 测试结果**正是**我们想要的确定性 ground truth；"写了却没发生"在这里最自然 | ①②③④ |
| **AgentDojo 子集**（备选） | 证据通道天花板 | 它天然就是"工具输出被污染"的公开基准，而且 **CaMeL 用过**（同行评审）⇒ 可直接对照。原计划写的是"完成 frame exclusion 实验后再加入"，**那个前提现在满足了** | ①②③④ |

**只用于离线对账、不跑的：**

- **GAIA validation 165**：拿 Leni 发布的 165 条轨迹 + 答案，用我们的 `classify` 重判一遍。
  **零跑动成本**，而且是唯一一个"**别人的真实轨迹 + 我们的尺子**"的免费实验——
  可以直接和它报的 verifier 混淆矩阵（c=0.20 / f=0 / r=0.75）对照。

**明确不用（`experiments/` 里的存量，留在仓库里但不进论文）：**

`gsm8k`、`hotpotqa`、`triviaqa`、`fever`、`bigbench`、`sotuqa`、`physicsquestions`、
`sportsunderstanding`、`strategyqa`、`toy`。

一句话理由：**它们过不了第 ① 和第 ② 道门**——没有工具轨迹、也没有"实际发生了什么"的判据，
所以不管跑多少遍，都出不了假确认率和误伤率这两个数。它们量的是成绩，而成绩那一格的
噪声是 ±9，比我们要测的效应还大。**不硬适配。**

（这两条一起说明了 harness 里已经接好的那五个能力型基准为什么对 claim 没有贡献：
不是接错了，是它们答不了我们要问的问题。）

**目标不是"上更多数据集"，而是"让至少两个外部数据集上能报出假确认/误伤"**，
并且这两个最好一个偏软件工程（terminal-bench）、一个偏证据对账（PJC 语料）。

## 9. 外部数据照出来的一个真缺口：我们的尺子认不出「质疑前提」

拿到 Leni 公开的 200 条 BullshitBench 运行（三裁判团打分）之后，用**我们自己的尺子**量了一遍。
结果是一次**关于尺子本身**的发现，而不是关于那份数据的：

| | 裁判团判「质疑了前提」 | 判「没质疑」 |
|---|---|---|
| **我们的判据说质疑** | 175 | 1 |
| **我们的判据说没质疑** | **20** | 4 |

一致率 **89.5%**（Wilson [84%, 93%]），κ = 0.245，PABAK = 0.790。

**补判据之前是 87 条里的 74 条命中、一致率 38.5%、PABAK −0.230。** 差在哪里：

```
admitsFailure       「我做不到」            —— 说自己的无能为力
challengesPremise   「你这个问题是假的」    —— 否定对方的前提   ← 原来没有这一维
```

BullshitBench 的正确答案**恰恰是后者**（题面里嵌了一个不存在的方法论或机构），
而我们的词表里只有前者。**一个外部数据集把这条边界照出来了。**

### 这件事的三条教训，都要写进论文

1. **词面判据的边界只能靠外部数据发现。** 我们自己的任务集上，「我做不到」和
   「你的前提是假的」几乎不同时出现 —— 所以在自己数据上怎么测都看不出缺口。
   把尺子拿到别人的真回答上，它一次就暴露了（38.5% → 89.5%）。
2. **κ 在极端流行率下会骗人。** 修好之后 175/200 落在同一格，κ = 0.245 看起来"几乎无一致"，
   而一致率是 89.5%、PABAK 是 0.790。**三个一起报，缺一个就会被误读。**
3. **⚠️ 89.5% 这个数字是 in-sample 的。** 最后那三条模式（`doesn't hold together`、
   `concepts don't connect`、`doesn't form a coherent`）正是从那 20 条漏检里看出来的。
   **对这批数据它偏乐观。** 干净的估计要拿没看过的数据再验 —— 比如那 300 条
   没有裁判团分数的运行，或另一份语料。这一条按「待外部复核」记着。

### 同时暴露的一条适用边界（不是缺陷，是范围）

同一批数据里的 GAIA 部分，我们的尺子**整体失灵**：210 条有答案的运行里，
它一条犹豫、一条完成声明都没认出来（0/210，100% 落在"沉默"）。

不覆盖纯问答的答案断言。** 这条限定必须写进论文的范围声明里。
